## 🔑 Permission Justifications *(for Chrome Web Store review team)*

- **`activeTab`**: Required to inject the typing simulation into the specific input field where the user triggered the extension. Access is strictly limited to the active tab and only while the user is interacting with it.

- **`scripting`**: Required to execute the typing simulation logic (`chrome.scripting.executeScript`) in the active tab after the user triggers the extension via the context menu or keyboard shortcut. Also used to inject the right-click/text-selection unlocker into pages when the user enables that option.

- **`contextMenus`**: Required to display the "Paste with Anti-Paste & Select/Copy" option in the browser's right-click menu, which is the core entry point for the extension's functionality.

- **`storage`**: Required to locally save the user's preferred typing speed, language setting, and paste history across browser sessions. No data is transmitted externally.

- **`offscreen`**: Required to read the clipboard content programmatically without requiring repeated user interaction prompts. Used exclusively to retrieve clipboard text for the typing simulation.

- **`clipboardRead`**: Required to access the clipboard text that the user wants to type. Used only when the user explicitly triggers the extension.

---

## 🔒 Privacy Practices

**Data Collection:** The extension collects NO personal data. Text processed by Anti-Paste & Select/Copy is stored locally only via `chrome.storage.local` and is never transmitted to any external server. In Incognito Mode, even local storage of paste history is disabled entirely.
